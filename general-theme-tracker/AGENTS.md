# General Theme Tracker: agent entry point

Before working here, read [AGENT.md](AGENT.md), then
[RESEARCH_PLAYBOOK.md](RESEARCH_PLAYBOOK.md). The playbook is the executable
research procedure and acceptance checklist. It applies to this product only.

For routine research, modify weekly source YAML only. Never hand-edit published
JSON, change a renderer to fix content, or approve your own candidate. Read the
shared review doctrine linked from AGENT.md before freezing or reviewing.

For an explicitly requested layout change, use a separate frontend change, keep
published data untouched, and update the affected frontend contract digests.
The public GitHub Pages URL serves this directory's `index.html`; changing the
Vite app alone does not change that public page.

All product content, UI, prompts and repository documentation here are English.
